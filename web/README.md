# Travyon Web

Bu klasör React + Vite ile geliştirilen web uygulamasının tamamını içerir.

- `src/`: sayfalar, bileşenler, servisler ve state yönetimi
- `public/`: webde doğrudan sunulan statik dosyalar
- `tests/`: Vitest testleri
- `.env*`: yalnızca web istemcisinin ortam ayarları
- `dist/`: production derleme çıktısı; elle düzenlenmez

Komutları depo kökünde çalıştır:

```powershell
npm.cmd run dev
npm.cmd run build
npm.cmd test
```
