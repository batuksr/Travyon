# Welcome photograph

`welcome-istanbul.jpg` is a bundled copy of the Istanbul destination photograph
already used by `lib/features/hub/data/hub_content.dart` and the web city guide.
Bundling avoids a network request before sign-in and keeps the welcome usable offline.
